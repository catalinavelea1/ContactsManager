ContactsManager is an Android application developed in Kotlin that allows users to enter contact information and save it through the device's Contacts application.

--implementation--
- Implemented an XML-based interface for entering names, phone numbers, emails, and addresses.
- Added expandable fields for job title, company, website, and instant messaging details.
- Implemented input validation using Android Patterns and EditText error messages.
- Used Intent and the ContactsContract API to transfer contact details to the Contacts application.
- Used ContentValues to handle additional contact information.
- Implemented SAVE and CANCEL actions to initiate contact creation or close the activity.
